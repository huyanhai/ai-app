# Third-party skills

The following skills are copied from
[zenstory-ai/drama-skills](https://github.com/zenstory-ai/drama-skills):

- `short-drama-develop`
- `short-drama-write`
- `short-drama-assets`
- `short-drama-image-prompts`
- `short-drama-storyboard`
- `short-drama-video-prompts`

Only their `SKILL.md` content is loaded as creative guidance by the production
planner. Bundled scripts are not executed by the application.

The following skills are copied from
[HBAI-Ltd/Toonflow-app](https://github.com/HBAI-Ltd/Toonflow-app):

- `workflow`
- `storyboard`

The `elicitation-skill` is copied from
[alibaba/lumenx](https://github.com/alibaba/lumenx).

These skills provide creative guidance only. Project stage transitions and
user confirmation always take precedence; external tools and scripts are not
executed.
