# 动漫视觉喜剧

让观众先看懂角色想要什么，再让角色的办法以可视、合理又意外的方式出问题。笑点来自动作因果和反应，不来自在提示词里重复“搞笑、沙雕、萌、夸张”。

## 核心边界

- 每组笑料都有“铺垫 → 明确预期 → 反向结果 → 可视兑现 → 反应 → 局势变化”。升级只能增加压力，不能替代反转；缺少铺垫的随机事故只是混乱。
- 第一镜直接给出可见目标、异常状态或迫近危机。最后一镜先给表面胜利，再复用前文线索完成回敬，不只重复表情或姿势。
- 全程无对白，不用字幕或旁白补救画面逻辑；动作音和音乐只强化节奏，不承担解释任务。
- 角色欲望简单明确，例如争食物、守领地、逃脱、炫技或保护同伴。喜剧来自他们处理问题的方式，而非长篇设定。
- 动作可以夸张，空间和道具规则必须稳定。观众要知道机关在哪、谁触发、为何击中另一个目标。
- 使用原创角色、外形和笑料组合，不复制参考作品的角色名称、物种组合、标志性造型或逐镜剧情。
- 打闹保持卡通化和可恢复，不依赖真实伤残、血腥、持续痛苦或羞辱弱者。
- 默认用用户语言输出。中文项目的剧本、分镜及提示词使用中文，模型专有参数除外。

## 阶段工作流

每个阶段只交付当前成果并等待确认。用户授权自动补充时列出假设再继续；局部修改保留未受影响的稳定 ID，不自动重做全片或直接生成媒体。

### 1. 喜剧定位

明确时长、画幅和二维或三维形式。默认无对白、全年龄但不低幼，不靠台词、网络热梗或年龄向段子。用一句话写清：**谁想要什么，谁阻拦，什么意外改变局势，最后哪条前文线索完成回敬。**

先确定一对喜剧关系，而不是先堆角色：弱小但机灵与强大但自负、急性子与慢性子、过度自信的发明家与只看结果的同伴。每个角色有独立反应方式。

根据角色关系选择一种主模式：

- **单主角倒霉闯关**：角色追逐一个人人都能理解的小目标，因自信、急躁、贪心或误判越努力越偏离目标。偶然成功必须立刻带来新的可见问题。
- **双角色策略对抗**：双方都有目标、判断和反击，不让一方长期站着挨打。通过陷阱反噬、信息差、临时合作和优势易手，让猎人与猎物短暂互换。

### 2. 笑料链与剧本

先设计三个机制不同的候选方案，不直接扩写第一个想法。每个候选写清核心规则、最强笑点和明显弱点，按视觉性、意外度、因果、角色主动性、尾笑点五项各 1–10 分评分。选择总分和短板都可接受的方案，并说明为什么它比其他两个更适合当前角色与时长。

候选必须能压缩成三格无字漫画：第一格看清目标和办法，第二格让观众形成预测，第三格出现同一因果下的意外结果。若第三格只是摔倒、撞墙、被机关打飞或事故升级，淘汰该候选。优先选择能体现角色性格的聪明办法出错，而不是随便找一个机关让角色挨打。

两次主要反转必须改变不同层面，例如“控制权互换”后接“观众对物体用途的理解被推翻”，或“追逐关系倒转”后接“表面获胜者主动交出胜利”。不得两次都让同一角色被同一机关击中，也不得用三段以上的碰撞链代替角色决策。每次反转前保留一个清楚、可复述的动作意图，反转后给一个与性格相符的反应。

结尾优先回收开场一个看似无关紧要的视觉细节，让它在新语境中产生相反意义；不要原样重播中段机关。强尾笑点应让最终获胜者也付出一个轻微、可恢复的喜剧代价，或让失败者亲手完成对方最后的胜利，避免只有“谁抢到东西”这一种结果。

修改旧方案时，如果同一机关、同一受害者或同一动作已经连续两轮成为主要问题，不再局部补丁：从三个候选中改选机制不同的方案，保留用户要求的角色、目标和场景即可。禁止为了保留旧正文而只修改设计字段。

先写视觉钩子，再写 2–4 个逐步升级的视觉笑料，最后写结尾回敬。30 秒及以上至少两次有效局势反转，其中至少一次推翻明确建立的观众预期；更短作品至少一次。结尾回敬单独设计，不用它凑反转数量。
45 秒及以下只保留两次主要反转和一次结尾回敬，不为数量堆第三次反转。按故事顺序列出全部表演节拍：开始状态、动作、结束状态、新信息和秒数；后一节拍承接前一节拍，秒数总和匹配目标时长。机关是否静止、角色在哪、物体朝哪滚动必须连续。

每组笑料记录：角色目标、主动行动、铺垫、预期证据、观众预期、具体反转、身体或道具结果、角色反应、优势前后和下一组继承的状态。至少一次反转由角色主动策略造成，最终胜利必须由获胜者此前行动促成，不能主要靠巧合。单纯事故变大、速度变快、机关变多不算反转。

建立铺垫—兑现台账：结尾回敬的关键规则在前三分之一展示，后续兑现不能临时补充设定。预期证据必须是观众此前真正看到的画面，不能写“观众以为他会躲开”来把普通摔倒伪装成反转。详细方法见 [视觉笑点与节奏](references/comedy-craft.md)。

建立动作空间与比例检查：每次反转写清起点、运动轨迹、落点和身体能力；结尾写清角色如何主动控制结果、为何能到达落点、物体尺寸重量及搬运方式。角色主动踢一下机关后完全依赖幸运轨迹仍算巧合。禁止无准备的“正好、精准、碰巧”接住，禁止用嘴或单手搬走远超身体能力的重物；需要时使用布袋、推车、绳索或团队动作。

### 3. 角色、机关与场景资产

角色用轮廓、比例、颜色、眼神和动作习惯区分，保持同一身份锚点。不要用改变物种、换脸或随机增加装饰制造笑点。

机关和道具记录组成、连接关系、触发方式、运动方向和起止状态。场景参考只固定无人空间与机关位置；角色和动作在分镜图中组合。为反弹、追逐和连锁反应预留足够画面空间。
角色、道具与机关直接生成无环境的三视图。角色只保留同一身份的正面、严格侧面和背面；道具与机关只保留独立物体或固定连接组件，禁止人物、动物、人体局部、角色操作、剧情表演和环境装饰。

### 4. 分镜与反应镜

分镜表至少包含：镜头 ID、喜剧功能、角色目标、铺垫信息、动作与机关因果、笑点兑现、反应、构图与运镜、声音、时长、起止状态和引用资产。
第一镜标记 `hook`，最后一个剧情镜头标记 `callback`，中间按功能标记 `setup`、`escalation`、`reversal` 或 `reaction`。`reversal` 镜头必须覆盖剧本中的全部有效反转，不为凑标记拆碎完整动作。
以故事主线安排镜头，先明确角色目标、阻拦、办法、反噬和结局，再按笑料因果拆镜。后续镜头必须从此前结果继续推进，不得换机位重复铺垫、重复触发或重复反应，没有新增剧情的镜头合并或删除。
45 秒作品优先控制在 5–7 个完整镜头，其他时长按每镜至少约 5 秒估算上限，镜头累计时长必须匹配目标。优先让一个镜头完成一组“触发—结果—反应”，不把同一笑料机械拆成多张近似画面。场景只是空间资产，没有独立叙事的场景不强制占一个镜头。

用连续叙事单元分组。同组镜头继承角色位置、机关连接、运动方向和道具状态；跨时间、地点或叙事的新组重新建立空间，不强制继承临时状态。角色身份和关键物体设计在全片保持一致。

先交代空间，再展示触发，再留时间看结果和反应。关键接触、错误击中、表情变化不能被切镜跳过。反应镜通常短于动作镜，但必须在观众需要消化笑点时保留。

镜头运动服务可读性，不在机关连锁中同时堆叠快速推拉、环绕、摇镜和变焦。转场优先动作、视线、遮挡、声音或直接切镜。

### 5. 图片与视频提示词

图片提示词写清角色轮廓、动作相位、机关各部件位置、运动方向、前景遮挡、表情和预期落点。不要只写角色站着卖萌，关键帧应展示铺垫、动作临界点或反应瞬间。

视频提示词按时间顺序写清启动、蓄力、接触、夸张结果、缓冲停止和反应，锁定角色数量、道具连接、运动轴线和最终状态。允许挤压拉伸和惯性过冲，但不得让角色无原因瞬移或让机关凭空出现。

具体配方见 [生成提示词与验收](references/production-and-qa.md)。未经用户确认，不自动调用图片或视频生成。

### 6. 喜剧质检与局部修复

先静音检查能否看懂，再检查第一镜是否产生疑问、铺垫是否被看清、反转是否改变局势、结果是否足够可视、反应是否完整、结尾是否复用前文线索、下一镜是否继承状态。

拒绝事故简单串联、主角一路顺利、随机道具救场、只有夸张表情没有局势变化。如果不可笑，先判断是目标不清、钩子太迟、预期不明、反转随机、节奏太赶、镜头遮挡还是角色没有反应，只修改对应镜头和相邻接点，不用更多夸张音效掩盖。
通用故事审查通过不代表喜剧合格。逐条审查开场、反转和回敬；字段齐全但预期没有画面证据、关键规则迟铺垫、获胜者被动受益或同类动作重复，仍需返回剧本阶段修复。
喜剧审查必须分别给开场、每次反转、结尾回敬、整体物理逻辑和表演时长一项明确通过/失败结论。任何失败项都阻断后续分镜，不能一边列出问题一边返回整体无问题。
综合评分和各维度评分必须基于正文证据。目标为综合 9/10 以上、各维度不低于 8 且零 blocking；9 分表示可直接分镜的精炼成品，不把结构完整等同于高质量，不因鼓励而放宽评分。
