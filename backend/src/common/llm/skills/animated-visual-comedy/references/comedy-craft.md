# 视觉钩子、反转与节奏

## 先选喜剧方案，再扩写

先写三个机制不同的候选，例如“角色误判同一规则”“双方争夺控制权”“小弱点意外成为优势”。每个候选列出最强笑点和最大弱点，按视觉性、意外度、因果、角色主动性、尾笑点各 1–10 分评分。不要只换角色或道具，三个候选必须改变笑点产生的机制。

选型后再写完整故事。评分用于暴露短板，不用高分自我安慰；若最强方案仍存在被动获胜或尾笑点无法提前铺垫，应换方案或先修复。

### 9 分成品的额外门槛

- **三格可懂**：每组核心笑料能画成“办法—预测—意外结果”三格无字漫画。抽掉结构字段后，只看故事正文也能复述笑点。
- **性格必然**：换成没有性格缺陷的普通角色，这个失败就不会发生。自大、急躁、贪心或炫技必须直接导致错误选择，不能只是开头摆一个表情。
- **异质反转**：两次反转分别改变不同东西，例如控制权、追逐方向、物体用途、胜负定义或双方关系。两次击倒同一角色不构成两次有效反转。
- **短因果链**：单次兑现最好是一次触发和一个直接结果，最多三次清楚碰撞。超过三次仍在继续弹、撞、滚，通常是在用混乱掩盖笑点不足。
- **尾点增量**：结尾除决定物品归属，还要增加一层 reversal of meaning，例如守卫亲手把藏品送回小偷、成功者被自己的胜利姿势困住、以为损坏的东西反而完成目标。
- **可演节奏**：关键预测前留半拍，兑现后留反应。用动作数量估算时长，不把六段追逐和连续碰撞压成几句概述。

修订时先判断原方案还有没有最强笑点。如果修订意见集中在“又是被同一个机关打中、又是同一个人摔倒”，说明是选型失败，不是细节失败。保留题材与角色，换用不同喜剧引擎重写正文；不要连续叠加补丁。

## 策略与铺垫台账

每次反转记录：行动者、主动行动、策略/失误/意外、预期证据、优势前、优势后。至少一次反转由角色主动策略造成，最终获胜者必须通过自己的此前行动兑现胜利。

每个兑现绑定一条更早的铺垫。结尾回敬的关键规则在前三分之一展示，最好第一次只展示普通功能，第二次才在新语境中改变结果。禁止在结尾首次宣布“原来它会回弹、会通电、会复制”。

### 空间、比例与巧合控制

- 每次反转写清起点、轨迹、落点和身体能力。观众需要提前看见终点或能推断方向，不能在结果出现后临时补空间解释。
- 主动触发机关不等于控制结果。角色还要通过站位、角度、时机、承接工具或连续动作控制兑现，不能踢一下机关后只靠幸运接住。
- 物体尺寸、重量和搬运方式保持一致。半人高重物不能无说明地被嘴叼走或单手提起；可使用布袋、背包、推车、绳索、滚动或双方协作。
- “正好、精准、碰巧”只有在前文已经展示准备和控制时才成立，否则视为作者救场。

不合格示例：山羊踢一下护栏，纽扣连续碰撞后精准落进嘴里。问题不只是轨迹巧，还包括纽扣尺寸超过嘴部能力。有效改法：开场展示纽扣能沿展示台斜槽滚动；山羊提前把宽口布袋固定在斜槽终点，再转动展示台改变槽口方向，纽扣按已展示的斜槽滚入袋中。

伪反转示例：“观众以为獾会躲开护栏，结果獾摔倒。”观众并没有必须这样预期的证据，这只是普通事故。有效改法：獾此前两次轻松躲开同一护栏并得意展示步法；山羊看穿节奏后第三次改变护栏方向，獾按旧步法主动迎上护栏，山羊因此取得纽扣。

## 先建立主动机

第一镜不要只介绍地点或角色。让观众立刻看见一个简单目标、异常画面或迫近危机，并产生一个具体疑问：他能否吃到、能否逃脱、谁先抢到、这个东西为何反常。

钩子必须靠画面独立成立，并从进行中的冲突开始。角色站着微笑、环境空镜、标题卡或事后解释都不是有效钩子；长篇环境和姿势介绍后才出现目标也不算开场立即建立钩子。

## 两种喜剧引擎

### 单主角倒霉闯关

角色目标简单，失败来自稳定的性格缺陷或误判。每次补救都沿用已知规则，却让角色离目标更远。观众可以比角色早一步看懂危险，形成戏剧反讽。

推荐链条：迫切目标 → 小误判 → 反向结果 → 自信补救 → 短暂成功 → 成功暴露更大问题 → 前文细节回敬。

### 双角色策略对抗

双方都根据所见信息行动，都有得分和失误。笑点来自策略碰撞，而不是一方持续伤害另一方。每次反击后检查控制权、目标进度或危险归属是否改变。

推荐链条：抢夺或阻拦 → 一方占优 → 另一方利用规则反制 → 陷阱反噬 → 优势互换 → 表面胜利 → 前文机关回敬。

## 一组完整笑料

1. **目标**：角色此刻只要一个清楚的小目标。
2. **铺垫**：观众看清关键道具、空间规则或性格缺陷。
3. **明确预期**：角色和观众能预测接下来会发生什么。
4. **反向结果**：实际结果推翻预测，但仍符合已展示的规则。
5. **可视兑现**：错误击中、机关反噬、身体变形或身份暴露完整出现。
6. **反应**：当事人和旁观者给出符合性格的不同反应。
7. **局势变化**：控制权、目标进度、角色关系或危险归属发生改变。

只有“更响、更快、更大、更多”是升级，不是反转。角色被同一机关连续击中三次，也只是重复。结尾回敬必须再次改变结果，不能只让角色眨眼或微笑。

## 可组合的笑料机制

- **视线误导**：角色只盯着目标，观众却看见危险从另一侧靠近。
- **错误目标**：机关按规则正常运作，却击中启动者或真正的受益者另有其人。
- **优势易手**：弱者利用强者的武器、习惯或身体优势反过来得分。
- **延迟理解**：身体先遇到问题，角色停一拍才低头发现。
- **假胜利**：角色和观众都以为目标已经达成，随后发现代价或被忽略的线索。
- **规则复用**：第一次偶然成功，第二次照做却过度，第三次被对手利用。
- **冷静反应**：巨大混乱后只给短暂停顿、眨眼或慢慢转头，与动作规模形成反差。
- **尾笑点**：结尾再利用一次前面的规则，改变最后结果。

一组笑料突出一个主机制，其余只辅助。不要为了热闹同时堆满所有机制。

## 节奏与时长

30 秒及以上至少两次有效局势反转，其中至少一次推翻明确预期；更短作品至少一次。结尾回敬单独设计。每个镜头仍要完成一个完整叙事节拍，不为了凑反转拆碎动作。
45 秒及以下最多两次主要反转，另留一次结尾回敬。若还有第三个好想法，比较后删除较弱者，不让动作数量压垮铺垫和反应。

重复转圈、扑空、摔倒和得意反应若没有新信息就合并。时长按实际动作估算，不能靠文字压缩把一分钟表演塞进四十秒。

为全部表演建立状态链和秒数预算：每段记录开始状态、动作、结束状态、新信息和时长。下一段必须承接上一段的机关静止/运动、角色位置、目标进度和物体方向；只改变表情不算新信息。

9 分故事应同时满足：开场立即有戏、两次反转机制不同、角色主动控制结果、关键规则提前铺垫、结尾重新解释线索、物体与空间可信、表演能装进目标时长。字段完整但只有 6–7 分时继续删减和重写，不进入分镜。

开场尽快给出钩子。铺垫要看得清，最大反转前可短暂停顿，兑现后留反应时间。连续高速动作后安排一个安静反应或新目标，避免全片同一音量。

## 原创示例：松饼、弹簧灌木与自动餐车

圆滚小河狸与高傲长脚鹬争夺最后一块蜂蜜松饼。自动餐车有拉杆、托盘和刹车绳，旁边的灌木被压弯后会回弹。全片无对白。

| 喜剧功能 | 铺垫与明确预期 | 反向结果、兑现与局势变化 |
|---|---|---|
| hook | 河狸张大嘴，松饼已经到嘴边 | 长脚鹬的长喙从画外伸来瞬间截走；河狸咬空，观众追问谁能吃到 |
| setup | 河狸轻拉餐车拉杆，想把松饼弹回自己手中 | 长脚鹬凭长脖轻松接住；它的身高优势被明确建立 |
| reversal | 河狸把拉杆拉到底，预期松饼越过长脚鹬 | 松饼没动，托盘却把河狸弹进灌木；河狸从追击者变成被困者 |
| reversal | 长脚鹬靠近灌木炫耀，预期河狸无法反击 | 回弹灌木把河狸送回来，河狸顺走松饼并落进驾驶座；控制权互换 |
| escalation | 长脚鹬拉动刹车绳，餐车急停，预期能拦下河狸 | 河狸抱住松饼飞出去，长脚鹬伸喙接住松饼，形成表面胜利 |
| callback | 长脚鹬仰头准备吞下松饼，观众暂时接受它获胜 | 刹车绳自动收回，托盘合拢夹住长喙；松饼掉进刚落地的河狸嘴里，前文机关完成回敬 |

示例只说明钩子、优势易手、规则复用和结尾回敬。实际项目重新设计角色关系、道具规则和笑点，不照搬此例。
