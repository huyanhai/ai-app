# 生成提示词与验收

## 角色与视觉风格

用原创轮廓和比例区分角色，例如圆矮、细长、大头、小眼或夸张尾巴。风格描述锁定材质、线条、色彩、光照和细节程度，不使用“某工作室同款”代替美术设计。

可爱不等于所有角色都圆润。喜剧关系可以通过圆与长、矮与高、慢与快、简单与繁复的形状对比建立。表情锚点包括眉毛、眼睑、瞳孔、嘴部和身体重心。

## 分镜图提示词配方

1. 原创二维或三维动画风格、材质与统一色彩。
2. 角色数量、身份、轮廓、表情和引用资产。
3. 本镜动作相位：铺垫、蓄力、接触、结果或反应，而不是通用站姿。
4. 机关部件、连接关系、触发点、运动方向和目标位置。
5. 前后景、运动轴线、视线、出画空间及观众必须看见的信息。
6. 道具状态、角色衣物与身体形变程度。
7. 禁止无关角色、额外道具、文字水印和改变剧情逻辑的装饰。

场景参考图保持无人。角色、机关和动作在分镜图中组合，避免场景资产把某个笑料构图错误固定到全部镜头。

## 视频提示词配方

按时间顺序描述：

- 起始画面、引用角色与机关版本、角色目标和动作相位。
- 蓄力、触发、接触、运动轨迹、错误结果、停止或回弹。
- 哪个部位夸张、夸张到什么程度、何时恢复正常轮廓。
- 当事人和旁观者各自不同的反应及停留。
- 镜头何时固定、跟随或切换，始终保留关键接触和反应。
- 动作音、机关音、短暂停顿和音乐的关系；默认无对白，不用字幕或旁白解释笑点。
- 结束姿态、道具位置和下一镜继承的运动或声音。

不要同时要求“真实物理”与“任意夸张变形”。采用一致卡通物理：起跳有蓄力、飞行有轨迹、落地有缓冲、形变有恢复，结果可以夸大但过程可读。

## 验收

1. **静音理解**：无对白也能说出目标、意外和结果。
2. **开场钩子**：第一镜已经出现目标、异常或危机，观众有主动追问。
3. **有效反转**：结果违背明确预期并改变局势，不只是事故变大。
4. **结尾回敬**：表面胜利后复用前文线索，最终结果或关系再次变化。
5. **铺垫可见**：关键道具与空间在触发前至少被看清一次。
6. **因果成立**：结果由角色动作和已建立规则产生，不是随机新事件。
7. **兑现完整**：接触、击中、变形或错误结果没有被切掉。
8. **反应有效**：反应符合角色性格，并留出观众消化时间。
9. **升级有效**：后续笑料复用并提高前面的规则，不是无关段子串烧。
10. **连续一致**：角色数量、外形、道具连接、运动方向、场景位置和起止状态一致。
11. **媒体实测**：抽查每镜开头、关键接触、结尾和相邻镜接点；未实际检查的项目标“未测”。
12. **角色主动**：至少一次反转来自主动策略，最终胜利者不是靠连续好运获胜。
13. **铺垫时序**：回敬规则在前三分之一可见，兑现时没有临时补充设定。
14. **表演预算**：删除重复动作和反应后，剩余表演能真实装进目标时长。
15. **空间可控**：起点、轨迹和落点有依据，角色通过站位、角度或工具控制结果。
16. **比例可信**：尺寸、重量和搬运方式符合角色身体能力，没有无说明地嘴叼重物。
17. **状态承接**：相邻表演节拍的机关状态、角色位置、目标进度和物体方向连续。
18. **九分门槛**：综合评分至少 9、各维度至少 8、零 blocking；未达标只返回修改，不进入分镜。
19. **证据边界**：blocking 必须来自正文直接矛盾或关键动作缺失。角色已经低头、转身或被遮挡时，不再以“理论上可能被看见”判失败；空间与先后已写清时，不要求穷举所有意外可能。假设性风险只给 suggestion。

局部修复优先调整信息遮挡、动作相位、镜头长度和反应镜。若笑点本身没有铺垫或因果，返回笑料链阶段重做该组，不靠音效和字幕解释。
