# 古诗词真人微剧情

把诗转成一个普通人正在经历的小事件，而不是把诗句逐句翻译成唯美画面。观众应先理解人物在做什么、与谁相处、为什么产生情绪，再从结尾诗句或朗诵中感到诗意。

## 不可让出的创作边界

- 先生活，后诗意。人物必须有具体生活任务、眼前目标和自然反应，禁止连续摆拍、人物站着凝望、空镜堆砌。
- 一首诗只讲一个小事件。保留原诗核心意象和情绪，不为了制造戏剧强行增加战争、死亡、爱情或作者本人。
- 用事实与演绎分栏记录诗词原文、时代背景和合理补充。不得把虚构对白、人物关系或作者经历冒充史实。
- 古代生活可以质朴，情感必须能让当代观众理解。对白使用自然口语，不讲解诗词，不突然使用现代网络用语。
- 真人感来自皮肤、年龄、体态、衣物磨损、动作惯性和人物关系，不来自全员俊美、过度磨皮、浓妆、影楼写真或时装展示。
- 场景必须有人居住和使用的痕迹。减少无菌摄影棚、宏大宫殿、无尽烟雾、强逆光、慢动作和无关航拍。
- 默认用用户语言输出。中文项目的研究、剧本、分镜及提示词均使用中文，模型专有参数除外。

## 阶段工作流

每个阶段只交付当前成果并等待确认。用户要求自动补充时，列出合理假设再继续；用户指定修改时保留未受影响的内容和稳定 ID，不自动重做整片或直接生成媒体。

### 1. 研究与创作定位

核对作品名、作者、原文、明确意象、时空和情绪。分离可靠事实、常见解释与本次虚构演绎。已知画幅、时长、风格、是否朗诵等直接沿用，只追问会阻塞创作的信息。

交付一份简短研究摘要和一句创作定位：**谁，在完成什么日常事情，遇到什么小状况，最后情绪怎样变化。** 同时明确不采用的路线，例如“不做作者生平讲解，不做纯风光 MV”。

### 2. 生活化微剧情

先列 2–3 个可选生活事件，再根据用户选择或授权确定一个。事件须能承载原诗，不得只是借用诗名。

写人物关系、生活任务、小阻碍、自然反应和情绪收束。对白可以有简短照应、调侃、催促和未说完的话；允许无对白的动作段。诗词朗诵是画外音或结尾收束，不要求画面人物逐句对口型。

详细改编方法见 [生活化改编与导演规则](references/adaptation-and-directing.md)；需要示例时读同文件的《采莲曲》。

### 3. 人物、道具与场景资产

锁定真正出镜的人物及其关系、年龄、体态、职业、服装和当前状态。不要为只闻其声的人物盲目生成视觉资产；需要代入感时也不要一边写人物正式出镜、一边禁止其进入分镜。

关键道具记录材质、磨损、持物手、数量与起止状态。场景参考只固定无人环境、生活痕迹、光向和空间关系；人物在分镜图中通过角色资产加入。
角色和道具直接生成无环境的三视图。角色三视图只保留同一人物的正面、严格侧面和背面；道具三视图只保留独立物体或固定连接组件，禁止人物、动物、人体局部、角色操作、剧情表演和环境装饰。

### 4. 分镜与确认

以故事主线安排镜头，先明确先做什么、遇到什么、如何应对、结果怎样，再按动作因果和情绪变化拆镜，不按句数或场景数量机械分配。每镜至少具有一项有效增量：动作推进、关系变化、新信息或情绪反应；不得换机位重复讲述已交代的事情，没有新增剧情的镜头合并或删除。
30 秒作品优先控制在 4–5 个完整镜头，其他时长按每镜至少约 5 秒估算上限，镜头累计时长必须匹配目标。一个镜头尽量完成一个完整生活动作或叙事节拍，不把准备、动作、结果和反应机械拆开。场景只是空间资产，没有独立叙事的场景不强制占一个镜头。

用连续叙事单元分组。同组镜头继承人物位置、朝向、视线、持物手、道具状态和运动方向；跨时间、地点或叙事的新组重新建立空间，不强制继承临时状态。角色身份和关键物体设计在全片保持一致。

分镜表至少包含：镜头 ID、诗依据、人物与生活动作、关系或情绪增量、构图与运镜、声音、时长、起止状态和引用资产。主要动作完成后才结束镜头；相邻镜头检查轴线、视线、出入画方向、持物手和道具状态。

转场根据本对镜头设计，可采用动作承接、视线、声音、前景遮挡或直接切镜。只有画面和运动确实可接时才设计连续转场，不重复套用花瓣、水花或瞳孔。

### 5. 图片与视频提示词

图片提示词从进行中的动作瞬间出发，写清人物关系、生活任务、场景使用痕迹、自然光、镜头高度和此刻状态，避免“唯美站在画中”的静态 pose。

视频提示词写清参考资产、入场状态、完整动作因果、人物反应、镜头运动、声音、结束状态和相邻镜衔接。保留真实生活速度，不把所有动作都写成慢镜头。

具体配方和质检方法见 [生成提示词与验收](references/production-and-qa.md)。未经用户确认，不因写出提示词而自动调用图片或视频生成。

### 6. 质检与局部修复

依次检查：诗意是否仍在、生活是否可信、人物关系是否成立、每镜是否有增量、动作是否完整、资产是否连续、声音是否自然、转场是否有动机。

失败时先定位研究、剧本、资产、分镜、提示词或生成中的具体一层，只修改受影响镜头及其邻镜，不盲目整片重抽。
