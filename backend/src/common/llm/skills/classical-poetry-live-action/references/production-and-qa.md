# 生成提示词与验收

## 分镜图提示词配方

按项目实际字段组织，不必保留以下标题：

1. 真人历史生活剧静帧、当前时代和地点。
2. 本镜人物身份、关系、数量及引用角色资产。
3. 正在进行的一个主动作，以及动作前的瞬间状态。
4. 生活空间、功能性道具、使用痕迹和引用场景资产。
5. 人眼视角、景别、前后景关系、自然光方向与色彩。
6. 当前衣物湿度、污迹、持物手、道具数量和情绪反应。
7. 禁止现代物件、无关人物、文字水印、影楼摆拍和过度美化。

优先写“她正探身去够莲蓬，同伴在后座压低竹篓并稳住船”，不要只写“两位唯美采莲女在荷塘中”。场景参考图保持无人，角色与动作只在分镜图中组合。

## 视频提示词配方

依次写清：

- 引用的分镜首帧、人物、道具和场景版本。
- 起始动作相位与空间位置，人物正在做什么而非从静止 pose 醒来。
- 主动作的完整因果、一个自然反应及必要的背景生活动作。
- 运镜幅度与速度；无必要时使用固定或轻微跟随，不组合多个炫技运镜。
- 对白的说话人、对象和目的；朗诵标为画外音，不要求场内人物对口型。
- 现场动作声、环境声和音乐克制关系。
- 动作完成后的结束状态，以及下一镜需要的动作、视线或声音承接。
- 人物数量、服装、道具、建筑、光线和构图不得无故重置。

首尾帧只固定画面边界，不能替代中间表演设计。连续转场必须同时设计上一镜出场和下一镜入场；不合适时使用直接切镜。

## 声音与生活节奏

先保证动作完整，再决定镜长。对话按实测语音时长校准，不凭字数压缩表演。保留脚步、衣物、器具、水、火和远处生活的声音层次，音乐不得盖住自然反应。

## 验收顺序

1. **原文**：核心意象、情绪与作品版本没有张冠李戴；虚构内容未冒充史实。
2. **生活**：人物有事可做，动作有目的，道具被使用，环境不像空置影棚。
3. **关系**：对白有对象，反应有原因，人物不是互不相干的摆拍素材。
4. **代入**：至少一个细节能让观众理解人物的麻烦、默契、期待或失落。
5. **分镜**：每镜有增量，无连续重复空镜，主要动作完整。
6. **连续性**：人物脸、年龄、服装、持物手、数量、光向、湿污状态和出入画方向一致。
7. **媒体**：抽查每镜开头、中段、结尾和相邻镜接点；未实际检查的项目标“未测”，不得仅凭提示词宣称通过。

局部修复只更新受影响镜头、相邻接点及依赖资产。若问题来自剧本没有生活事件，应返回剧本阶段，不用更多风格形容词掩盖。
