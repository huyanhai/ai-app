# 画布拖拽与平移性能优化设计

## 目标

减少节点较多时拖拽节点和平移画布的主线程开销，包括选中节点后的拖拽，不改变画布交互、节点内容和历史记录行为。

## 已确认瓶颈

- 节点或连线每次变化都会生成新快照，并对前后两份完整快照执行 `JSON.stringify` 比较。拖拽节点会高频触发该过程，数据量随节点和媒体内容增长。
- 图片节点通过 `useViewport` 订阅完整视口。平移改变视口坐标时，所有图片节点都会重渲染，但节点仅在编辑标记的反向缩放中使用缩放值。
- 选中可生成节点后挂载的 `GeneratorCard` 通过 `useNodes` 订阅全部节点。拖拽任一节点都会重渲染工具卡和 Lexical 编辑器，尽管工具卡只需要引用候选节点的展示字段。
- 关联连线的流光动画叠加高斯模糊滤镜，在选中或悬停时持续产生额外绘制开销。
- 点击节点时同步挂载完整 `GeneratorCard` 和 Lexical 编辑器，阻塞节点选中态的首次绘制。

## 优化方案

### 快照比较

- 在 `frontend/app/pipeline/page.tsx` 中对快照节点和连线执行浅比较，替代两次完整 JSON 序列化。
- 保留现有快照生成、500ms 历史合并、600ms 防抖保存、撤销和重做逻辑。
- 依赖现有节点与连线的不可变更新方式；仅选中、拖拽标记或测量结果变化时不新增历史步骤。

### 视口订阅

- 在 `frontend/components/pipeline/nodes/node/image/index.tsx` 中仅订阅视口的缩放值，不再订阅平移坐标。
- 保留图片标记、删除按钮和缩放手柄现有的反向缩放效果。
- 不修改图片编辑器的独立视口逻辑。

### 生成工具卡订阅

- 将 `GeneratorCard` 的全节点订阅收窄为引用候选列表，只比较节点 ID、类型、标题、描述和媒体 URL 等实际使用字段。
- 节点位置、选中态和拖拽状态变化时，不重新渲染工具卡内容；引用候选的展示字段变化时正常更新。
- 保留外层 `NodeToolbar` 及其 `nodeId` 定位逻辑，工具卡继续跟随节点和画布视口移动。

### 连线流光绘制

- 保留蓝青渐变底色和现有流光动画。
- 移除流光路径的高斯模糊滤镜及不再使用的滤镜定义，降低持续重绘成本。

### 生成工具卡首次挂载

- 使用 React `useDeferredValue` 延后底部生成工具卡的挂载，让节点选中反馈和顶部媒体工具条优先绘制。
- 不使用固定延时，不拆分或简化 Lexical 编辑器功能。
- 等延后渲染的生成工具卡就绪后，再执行现有的节点与工具卡整体定位，避免重复定位或工具卡超出屏幕。

## 不在本次范围

- 不启用 `onlyRenderVisibleElements`，避免离屏节点卸载导致编辑器或草稿等本地状态丢失。
- 不增加拖拽简版节点、交互降级渲染或新的状态管理抽象。
- 不调整画布功能、布局、交互和后端接口；视觉变化仅限移除连线流光模糊。

## 验证

- 运行前端 lint 和构建，确认类型与依赖使用正确。
- 在多节点画布中连续拖拽节点，确认移动跟手，连续拖拽仍合并为一个历史步骤。
- 平移和缩放画布，确认节点内容、选中态与连线正常。
- 编辑带标记的图片，确认标记、删除按钮和缩放手柄在缩放后保持原有尺寸与行为。
- 选中带生成工具卡的节点并拖拽、平移和缩放，确认工具卡正常跟随，引用列表在内容变化后正常更新。
- 点击未选中的生成节点，确认选中反馈优先出现，生成工具卡随后显示且内容完整。
- 选中靠近视口底部的节点，确认生成工具卡挂载后自动定位正常。
- 选中或悬停节点，确认关联连线保留渐变流光。
- 验证撤销、重做和刷新后的自动保存恢复不受影响。
