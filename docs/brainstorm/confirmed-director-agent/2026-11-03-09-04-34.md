# 需求驱动与全阶段确认的导演 Agent

## 目标

借鉴 Toonflow 的会话式提问、专业分工与工具边界，以及 LumenX 的结构化制作阶段和人工确认工作台。导演 Agent 负责理解需求、组织阶段产物和响应修改；后端状态机始终拥有阶段推进权，任何阶段未经用户确认都不能进入下一阶段。

## 方案

采用“导演 Agent 编排 + 确定性后端门控”。不让模型自由决定跳过阶段，不在第一版引入可递归委派或并行修改画布的自主子 Agent。专业 Agent 仍通过独立 Planner 和结构化 Schema 产出结果，导演层负责需求摘要、阶段说明、提问和结果汇总。

## 用户流程

1. **需求澄清**：识别创意、来源材料、目标时长、类型、视觉风格、画幅、语言和媒体偏好。只询问会影响结果且无法合理判断的缺项，每轮最多三个问题，不重复询问已知信息。
2. **需求摘要确认**：汇总用户原始要求、合理创作补充和待确认项。用户确认或补充后才生成剧本。
3. **剧本确认**：生成完整故事与场景剧本，等待确认或修改。
4. **角色确认**：根据已确认剧本生成角色设定，等待确认或修改。
5. **分镜确认**：生成全片唯一分镜 Table 中的镜头内容，等待确认或修改。
6. **分镜图提示词确认**：根据已确认分镜生成静态关键帧提示词，等待确认或修改。
7. **视频拍摄提示词确认**：结合剧本、分镜和已确认图片提示词生成视频提示词，等待确认或修改。
8. **参考图确认**：生成角色与场景参考图，展示成功和失败结果；用户确认、重生成或修改后才继续。
9. **分镜图确认**：生成各镜头关键帧，等待用户确认或重生成。
10. **视频确认**：生成镜头视频，等待用户确认最终结果或重生成失败、未采用项。

媒体自动模式只在当前媒体阶段内批量执行，完成后必须停在对应审核状态；手动模式允许用户逐项或分批启动。两种模式都不能自动跨过用户确认。

## 状态与接口

- 项目状态按 `requirements`、`script`、`characters`、`storyboard`、`imagePrompts`、`videoPrompts`、`references`、`storyboardImages`、`videos` 分为 `pending`、`review` 和媒体 `running` 状态。
- 每次生成前持久化当前版本和开始事件，完成后持久化结构化结果并进入审核状态。
- 确认接口只接受当前阶段的唯一合法后继；前端禁用按钮不是权限边界。
- 修改接口覆盖所有文本阶段；媒体阶段支持失败项和用户未采用项重生成，不默认重跑已成功且已采用项。
- 需求不清时返回结构化提问卡片，支持选项和自由回答；跳过提问不等于确认需求或授权下一阶段。
- 延续现有 SSE：开始、提问、流式片段、结果和失败事件分别传输；等待用户期间不保持模型执行轮次。

## 数据与画布

- 项目保存需求摘要、问答记录、各阶段版本、确认时间、修改意见和采用状态。
- 已确认上游版本是下游 Planner 的输入；上游修改后，仅受影响下游标记为待更新，不自动删除历史结果或产生费用。
- 保持全片唯一分镜 Table，集中展示分镜、分镜图提示词和视频拍摄提示词。
- 媒体节点记录生成状态、结果、失败原因、采用状态和来源版本；确认媒体阶段不代表重生成。

## Skills 复用与适配

- **LumenX `elicitation-skill`**：借鉴先提问后执行、问题数量限制和 Intent Brief，改写为影视需求澄清，不采用其中与产品开发访谈相关的问题。
- **Toonflow `workflow`**：选择性借鉴 `sourceAndScript`、资产连续性和 `stateAndDelivery` 的版本确认规则；不采用 Seedance 强制路由、特定工具名称或其画布存储结构。
- **Toonflow `storyboardTeam`**：借鉴导演统筹、分镜编写和连续性审阅职责，第一版由结构化 Planner 和校验器实现，不引入递归委派。
- **LumenX 风格预设**：作为视觉风格推荐知识，保留用户自定义覆盖，不自动改变已确认资产。
- **现有 `drama-skills`**：继续作为剧本、角色、分镜和提示词创作知识。
- 所有借鉴内容保留 MIT 来源与许可。技能规则始终从属于项目状态机、用户明确要求和结构化输出契约，不执行外部技能脚本。

## 验证

- 模糊创意先提问，未回答或跳过不能生成剧本；完整需求不重复提问。
- 每个阶段未确认时，下一阶段 Planner 或媒体服务均不会被调用。
- 自动媒体模式在当前批次结束后停止等待确认，手动模式只执行用户启动项。
- 修改上游后保留下游历史结果并正确标记待更新，重新确认前不产生费用。
- 覆盖需求、文本、提示词、媒体阶段测试及 SSE 提问事件；前后端构建通过，测试不调用真实付费生成。
