# 3D 导演台前端复刻设计

## 目标

点击画布的“导演台”节点后进入独立页面。页面使用 React Three Fiber 复刻即梦导演台的 UI、3D 场景和前端交互。首版不接入后端，不修改参考网站的数据。

## 技术方案

- 使用 Next.js 现有路由新增 `/pipeline/stage/[nodeId]` 页面，关闭页面后返回 `/pipeline`。
- 使用 `three`、`@react-three/fiber` 和 `@react-three/drei` 实现场景、控制器、变换手柄和视角指示器。
- 使用 React 状态管理预演模式、对象、摄像机、环境、灯光和面板状态。状态仅保留在当前页面会话中。
- 优先下载并本地保存参考页面可公开访问的模型、环境贴图、图标和缩略图，记录资源来源；无法复用的资源使用本地等效实现，不依赖跨域热链。

## 页面与交互

### 顶部与场景

- 复刻顶部标题、保存状态、静态/动态预演、拍摄、镜头素材和返回画布控件。
- 使用深色全屏布局，还原左侧工具栏、右侧对象/属性面板、机位预览和底部视角控件的位置、尺寸、颜色、边框及层级。
- 静态预演支持导演视角和机位实时预览；动态预演展示对应播放控件并驱动前端场景动画。
- 拍摄生成当前机位的前端预览素材，加入镜头素材列表；不上传或持久化素材。

### 3D 对象

- 场景包含地面、网格、主光、补光、轮廓光和默认机位。
- 支持对象搜索、展开、选择、聚焦、锁定和实时预览开关。
- 支持选择、移动、旋转、缩放、落到地面及 `0`、`1`、`2`、`3`、`G` 快捷键。
- 支持导演视角旋转、缩放、平移、重置，以及机位预览折叠、尺寸调整和分屏预览。

### 属性面板

- 支持环境预设、背景颜色、地面颜色、地面显示、地面不透明度、曝光和网格开关。
- 支持主光、补光、轮廓光的颜色、强度及参考页面提供的角度和阴影参数。
- 数值支持直接输入和横向拖拽；修改立即反映到 3D 场景。
- 右侧面板可展开、收起和滚动，小高度窗口中保持顶部与场景控件可用。

## 状态与边界

- 页面内的添加、选择、变换、拍摄和保存状态均在前端运行。
- “保存”将当前场景序列化到浏览器本地存储，并显示已保存状态；刷新后恢复该节点的前端场景。
- 不实现账号、分享、会员、云端协同、AI 生成和后端素材库。
- 不修改现有画布其他节点的行为，仅补充导演台节点跳转。

## 验收标准

- 点击任一导演台节点进入带对应 `nodeId` 的独立页面，返回按钮回到画布。
- 在 1440×900 桌面视口下，布局、文案、图标、颜色和交互层级与参考页面一致。
- 所有可见控件均有前端响应，无仅用于装饰的无效按钮。
- 对象变换、环境、灯光和摄像机操作实时更新场景；快捷键不会破坏输入框编辑。
- 页面刷新后恢复本地保存的场景；未保存修改有明确状态提示。
- 前端 lint、生产构建通过，并在浏览器中验证节点跳转和主要交互。
