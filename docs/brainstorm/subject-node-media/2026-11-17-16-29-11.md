# 主体节点素材绑定设计

## 目标

将即梦主体节点的核心素材能力同步到现有 `subjectNode`：主素材、音色、来源选择和下游引用。保留当前节点结构与画布保存方式，不建设账号级主体资产体系。

## 范围

- 编辑主体名称和描述。
- 从画布图片、主体库或本地文件绑定主素材。
- 从节点右上角入口添加、试听、替换和移除音色。
- 通过 `@主体` 将名称、描述和主图传给图片或视频生成流程。
- 保存并重新加载全部主体素材。

音色仅作为主体资产管理。现有生成模型没有音频参考输入，本次不修改模型供应商协议，也不宣称音色会参与生成。

## 方案

扩展现有主体节点和资产弹窗，复用画布节点、主体库、本地上传与画布历史能力。不新增独立选择器或后端主体实体。

### 数据

主体节点沿用 `name`、`description`，增加：

- `url?: string`：主图片，兼作主体缩略图和现有引用字段。
- `voiceUrl?: string`：参考音频。

后端画布节点校验允许这两个字段。旧主体节点缺少字段时显示空素材槽，无需迁移。

### 节点交互

- 主素材区域显示图片预览；空状态提供添加入口。
- 不展示辅助素材区域。
- 节点右上角显示音色入口，弹层提供画布、资产库、本地添加和智能配音；绑定后可试听、替换和移除。
- 智能配音先将主体主图和描述发送给文本模型生成短台词（有图时使用支持视觉的模型），再将台词发送给音频模型；生成期间在入口显示 loading，结果保存到当前主体的 `voiceUrl`，不创建新节点。
- 已绑定音色点击后先显示播放器，通过更多操作展开替换和删除菜单；hover 显示快捷提示与移除入口。
- 名称、描述和素材变更直接更新对应节点，沿用现有撤销与保存流程。
- 导入主体更新名称、描述和主图，保留已有音色，避免隐式清除数据。

### 来源选择

资产弹窗增加主体绑定模式，记录目标节点和目标槽位：

- “导入主体”打开主体库并应用主体名称、描述和主图。
- “从画布选择”列出具有有效 `url` 的图片节点。
- “从资产库选择”复用主体库内容。
- “本地添加”接受图片；音色入口接受音频。

选择主图或音色时只更新目标槽位，不创建额外素材节点。普通工具栏打开资产弹窗时保留现有导入行为。

本地文件先转为数据 URL，再通过现有素材上传接口换取持久地址。上传期间禁用对应操作，失败时保留原数据并显示错误。

### 生成引用

扩展主体引用和编辑器 token，使其携带主体视觉参考地址：

- 文本部分包含主体名称和描述。
- 图片部分包含主图。
- 已插入的 token 随主体名称、描述或素材变化同步更新。
- 普通图片、视频、音频和文本引用保持现有行为。

## 验证

- 检查空主体、完整主体和旧版本主体节点的渲染。
- 验证主体库、画布图片和本地图片三种绑定来源。
- 验证音色的添加、试听、替换、移除和重新加载。
- 验证 `@主体` 生成请求包含主图，不包含辅助图或音色。
- 运行前端定向 lint、前端构建及相关后端测试。

## 非目标

- 账号级云端主体同步。
- 主体分类、搜索、权限和分享。
- 音色克隆或供应商音频参考协议改造。
- 与主体素材无关的画布重构。
