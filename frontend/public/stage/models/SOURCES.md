# 角色模型来源

- `xbot.fbx`：Three.js 仓库中的 Mixamo 人偶模型。
- 原始地址：`https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/models/fbx/mixamo.fbx`
- `ybot.fbx`：Mixamo Y Bot 女性人偶模型，取自 `jtydhr88/sd-3dmodel-loader` 仓库。
- 原始地址：`https://raw.githubusercontent.com/jtydhr88/sd-3dmodel-loader/3605e2168f229b14ac86c65063c1959408cd9dda/models/body/ybot.fbx`
- 用途：导演台男性、女性角色使用不同的真实骨骼模型，加载时转换为参考图的灰色分节材质，并按少年、儿童和体型预设调整比例。
